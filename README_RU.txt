==========================================================
  CHAIN CLIENT (Minecraft 1.21, Fabric) - ПОДРОБНАЯ ИНСТРУКЦИЯ
==========================================================

В этом архиве ИСХОДНЫЙ КОД. В игру кладётся не он, а готовый файл
chain-client-1.0.0.jar. Его бесплатно соберёт для тебя сайт GitHub.
Всё делается на компьютере с Windows. Ничего программировать не нужно.

Всего три части:
  ЧАСТЬ 1. Получить готовый файл мода (jar) через GitHub.
  ЧАСТЬ 2. Установить Fabric и положить мод в игру.
  ЧАСТЬ 3. Как пользоваться клиентом.


==========================================================
  ЧАСТЬ 1. СБОРКА МОДА ЧЕРЕЗ GITHUB
==========================================================

ШАГ 1. Распакуй архив
  1. Найди файл chain-client.zip, нажми на нём правой кнопкой мыши.
  2. Выбери "Извлечь всё..." -> "Извлечь".
  3. Открой появившуюся папку. Внутри должны быть:
       src, gradle, build.gradle, settings.gradle, gradle.properties,
       gradlew, gradlew.bat  (и скрытая папка .github).
     Если внутри только ещё одна папка chain-client, зайди в неё.
     Дальше всегда работаем с папкой, где лежит build.gradle.

ШАГ 2. Зарегистрируйся на GitHub
  1. Открой https://github.com и нажми "Sign up".
  2. Введи почту, придумай пароль и имя пользователя.
  3. GitHub пришлёт на почту код. Введи его на сайте.
  4. Пройди проверку (картинки) и пропусти все вопросы кнопкой Skip.

ШАГ 3. Создай репозиторий (это "папка проекта" на сайте)
  1. Вверху справа нажми "+" -> "New repository".
  2. В поле Repository name напиши:  chain-client
  3. Выбери  Public  (для публичных репозиториев сборка бесплатна).
  4. Больше ничего не трогай, нажми зелёную кнопку "Create repository".

ШАГ 4. Загрузи файлы
  1. На странице нового репозитория найди ссылку
     "uploading an existing file" и нажми на неё.
  2. Открой папку проекта (где лежит build.gradle).
     Нажми Ctrl+A (выделить всё) и перетащи всё выделенное мышкой
     в окно браузера, в область "Drag files here".
  3. Подожди, пока загрузятся все файлы (около 45 штук).
  4. Внизу нажми зелёную кнопку "Commit changes".

ШАГ 5. Проверь, что загрузилась папка .github
  1. Открой главную страницу репозитория (вкладка "Code").
  2. В списке файлов должна быть папка  .github
  3. Если её НЕТ (она скрытая и могла не перетащиться), создай файл вручную:
       - нажми "Add file" -> "Create new file";
       - в поле имени введи ровно:  .github/workflows/build.yml
         (когда напишешь слэш, сайт сам создаст папки);
       - в большое поле ниже вставь этот текст целиком:

name: Build Chain Client
on:
  push:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 21
      - uses: gradle/actions/setup-gradle@v4
        with:
          gradle-version: 8.8
      - name: Build
        run: gradle build --no-daemon
      - name: Upload jar
        uses: actions/upload-artifact@v4
        with:
          name: chain-client-jar
          path: |
            build/libs/*.jar
            !build/libs/*-dev.jar
            !build/libs/*-sources.jar
          if-no-files-found: error

       - нажми "Commit changes..." -> "Commit changes".

ШАГ 6. Дождись сборки
  1. Вверху репозитория открой вкладку "Actions".
  2. Если появилась кнопка "I understand my workflows, go ahead and
     enable them", нажми её.
  3. Должна появиться строка со сборкой "Build Chain Client".
     Если сборка не стартовала сама: слева выбери "Build Chain Client",
     справа нажми "Run workflow" -> зелёная "Run workflow".
  4. Жди 3-8 минут (первый раз долго, скачивается Minecraft).
       жёлтый кружок = идёт сборка
       зелёная галочка = готово
       красный крестик = ошибка (см. ШАГ 8)

ШАГ 7. Скачай готовый мод
  1. Нажми на название завершённой сборки (с зелёной галочкой).
  2. Прокрути страницу вниз до раздела "Artifacts".
  3. Нажми на  chain-client-jar  - скачается zip-файл.
  4. Распакуй его (правая кнопка -> "Извлечь всё"). Внутри будет
     файл  chain-client-1.0.0.jar  - это и есть твой мод.

ШАГ 8. Если сборка с красным крестиком
  1. Нажми на неё, затем слева на задачу "build".
  2. Разверни шаг "Build" (стрелочка слева) и найди красные строки
     со словом "error".
  3. Скопируй их текст и пришли в чат - я исправлю код.
     Исправленные файлы заменяй так: в репозитории открой файл,
     нажми значок карандаша, вставь новый код, "Commit changes".
     Сборка запустится заново сама.


==========================================================
  ЧАСТЬ 2. УСТАНОВКА В ИГРУ
==========================================================

Нужны: официальный Minecraft Launcher (Java Edition), его можно
скачать на minecraft.net. Используй версию игры 1.21 (подойдёт и 1.21.1).
Java ставить не нужно, лаунчер использует свою.

ШАГ 1. Запусти 1.21 один раз
  1. Открой Minecraft Launcher, слева выбери Java Edition.
  2. Внизу слева стрелочка рядом с "Latest release" -> "Installations"
     -> "New installation" -> Version: release 1.21 -> Create.
  3. Выбери эту установку и нажми "Play". Дождись главного меню
     и закрой игру. Это нужно, чтобы скачались файлы игры.

ШАГ 2. Поставь Fabric
  1. Открой https://fabricmc.net/use/installer/
  2. Нажми "Download for Windows" (файл .exe) и запусти его.
     (Если Windows ругается, нажми "Подробнее" -> "Выполнить в любом случае".)
  3. Вкладка "Client". Minecraft Version: 1.21
     Loader Version: оставь по умолчанию.
     Галочка "Create profile" должна стоять.
  4. Нажми "Install". Появится сообщение об успехе. Закрой установщик.

ШАГ 3. Скачай Fabric API
  1. Открой https://modrinth.com/mod/fabric-api/versions
  2. Слева в фильтрах: Game version = 1.21, Platform = Fabric.
  3. Скачай файл вида  fabric-api-0.102.0+1.21.jar  (нажми на стрелку вниз).

ШАГ 4. Положи моды в папку mods
  1. Нажми клавиши Win+R, введи:  %appdata%\.minecraft  и нажми Enter.
  2. Если папки  mods  нет, создай её (правая кнопка -> Создать -> Папку,
     имя строго  mods  маленькими буквами).
  3. Скопируй в mods ДВА файла:
       - chain-client-1.0.0.jar   (из Части 1)
       - fabric-api-0.102.0+1.21.jar   (из шага 3)
     Другие файлы, например "-dev" или "-sources", класть НЕ нужно.

ШАГ 5. Запусти
  1. В лаунчере внизу слева выбери установку  fabric-loader-1.21
     (она появилась после установки Fabric) и нажми "Play".
  2. Предупреждение о модах можно принять.
  3. Зайди в мир. В левом верхнем углу должна появиться надпись
     "Chain Client | ник | FPS". Если она есть, мод работает.


==========================================================
  ЧАСТЬ 3. КАК ПОЛЬЗОВАТЬСЯ
==========================================================

МЕНЮ (ClickGUI): нажми правый Shift (RShift) в мире. Закрыть: RShift или Esc.
  - Левая кнопка мыши по модулю  = включить / выключить.
  - Правая кнопка мыши по модулю = открыть его настройки.
  - Средняя кнопка мыши (колёсико) по модулю = назначить клавишу,
    потом нажми нужную клавишу. Delete = убрать клавишу, Esc = отмена.
  - Слайдеры настроек тяни мышкой, переключатели жми левой кнопкой,
    режимы (Mode) листаются левой кнопкой вперёд, правой назад.
  - Панели можно перетаскивать за заголовок, правая кнопка по заголовку
    сворачивает панель.
  - Настройки и клавиши сохраняются сами в файле
    .minecraft\config\chainclient.json

МОДУЛИ И КЛАВИШИ ПО УМОЛЧАНИЮ
  Combat
    KillAura (R)     - бьёт ближайшую цель, есть дальность, типы целей,
                       поворот, "только криты", "через стены".
    TriggerBot (G)   - бьёт, когда прицел наведён на цель.
    CrystalAura (C)  - ставит кристаллы на обсидиан и взрывает их у цели.
                       Нужны кристаллы в хотбаре и обсидиан рядом.
    AnchorAura (V)   - якорь возрождения: поставить, зарядить, взорвать.
                       Нужны якорь и светокамень в хотбаре.
                       Работает в Верхнем мире и Энде, не в Незере.
    AutoTotem        - держит тотем бессмертия в левой руке.
  Movement
    Sprint (B)       - автоспринт (есть режим "Omni sprint").
    Flight (X)       - полёт (режимы Motion и Creative).
    Speed (Z)        - ускорение (есть автопрыжок).
  Player
    NoFall           - убирает урон от падения.
    Scaffold         - ставит блоки под ногами при ходьбе.
  Render
    ESP              - подсветка игроков/мобов сквозь стены.
    Fullbright       - полная яркость.
    HUD              - надпись-ватермарк, список включённых модулей,
                       координаты и цветовая тема (Purple, Blue, Green,
                       Red, Rainbow).
  Misc
    AutoRespawn      - сам возрождает после смерти.

Клавиши модулей не работают, пока открыт чат или любое меню.
Хочешь другие клавиши, назначь их средней кнопкой мыши в ClickGUI.


==========================================================
  ЧАСТЫЕ ПРОБЛЕМЫ
==========================================================

- Игра пишет "Incompatible mods" / не запускается:
    не положен Fabric API или версия не 1.21. Проверь Часть 2, шаги 3-4.
- Нет надписи Chain Client:
    jar лежит не в .minecraft\mods, либо запущена не установка Fabric.
    Проверь, что внизу слева в лаунчере выбран fabric-loader-1.21.
- RShift не открывает меню:
    нажимай именно ПРАВЫЙ Shift и находясь в мире, а не в чате.
    Клавишу можно сменить в конфиге или в самом меню (СКМ по модулю).
- Игра вылетает при запуске:
    пришли мне файл .minecraft\logs\latest.log (или последние 40 строк).
- Сборка на GitHub красная:
    смотри Часть 1, шаг 8.

ВАЖНО: на большинстве публичных серверов читы запрещены, античиты
банят аккаунты быстро. Безопаснее пробовать в одиночной игре или
на своём сервере.
